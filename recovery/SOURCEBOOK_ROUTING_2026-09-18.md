# Economy Engine Sourcebook Routing

Date: 2026-09-18
Status: binding development procedure for sourcebook-derived constants
Campaign time advance: forbidden by this document
Notion writes: forbidden by this document

## Authority order

1. USER-RULED campaign facts.
2. Live Notion campaign canon and current-state authorities.
3. Ratified campaign skills/protocols.
4. The New Path Engine book-RAW reference layer.
5. User Library/sourcebook extractions not yet harvested into The New Path Engine.
6. External historical/engineering sources.
7. MODEL-PROPOSED values remain non-executable until separately ratified.

## The New Path Engine

Repository: `CFhacky/the-new-path-engine`

Read-first files:
- `AUTHORITY.md`
- `reference/README.md`
- `reference/families.json`
- `docs/harvest/STATUS.md`

The reference layer currently contains 18,296 accepted mechanical entries across
43 registered families and nine system labels. It is book RAW with per-entry
source/citation provenance. It is not campaign canon.

The repository explicitly states that the indexed reference layer is a
high-value slice, not the whole sourcebook corpus. The external corpus contains
roughly 1,700 OCR'd Markdown extractions; Forgotten Realms and broader mundane
economy material are not comprehensively indexed.

## Economy-engine rule

Before adopting a sourcebook-derived price, payload, travel rule, gear property,
spell effect, creature capacity, cost-of-living value, or other mechanical
constant:

1. Search The New Path Engine reference layer.
2. If no covered family contains the needed datum, search the user's Library /
   sourcebook corpus.
3. Only then use an external source.

Do not translate absence from an indexed family into absence from the sourcebook
corpus.

## Provenance labels

- Campaign fact from user / current Notion: USER-RULED or SOURCE-DERIVED.
- Book-RAW value from The New Path Engine: SOURCEBOOK-RAW.
- Book-RAW value recovered directly from the Library corpus: SOURCEBOOK-RAW.
- External historical / engineering constant: UPSTREAM-ADOPTED.
- Proposed bridging assumption: MODEL-PROPOSED and non-executable.

## Current economy implications

The historical Conestoga / FAO transport benchmarks already recovered remain
useful comparators, but they no longer control sourcebook-facing research.
Before settling ordinary fantasy wagon, animal, market-price, ration, wage, or
cost-of-living constants, query The New Path Engine and the sourcebook corpus.

No New Path Engine entry may override an explicit Baen-specific campaign fact,
such as the sourced 20-40 ton specialized heavy-stone wagon load.
